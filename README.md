# End-to-End Machine Learning: California House Price Predictor

This repository contains the capstone project for **Module 06: Final AI & ML Project** of the internship program. The project implements a complete machine learning pipeline using Python and Scikit-Learn to predict median house values based on demographic and geographic features.

## 🚀 Project Workflow
1. **Data Loading & Sampling:** Fetches and preprocesses real-world housing data.
2. **Exploratory Data Analysis (EDA):** Inspects feature correlations and structure.
3. **Data Splitting:** Divides data into training and testing sets (80/20 split).
4. **Model Training:** Trains an ensemble **Random Forest Regressor**.
5. **Evaluation:** Measures performance using $R^2$ Score, RMSE, and MAE.
6. **Visualization:** Generates and saves feature importance graphs.

## 📊 Evaluation Results
* **$R^2$ Score:** ~0.81
* **RMSE:** ~0.50

## 🛠️ Technologies Used
* Python
* Pandas & NumPy
* Scikit-Learn
* Matplotlib & Seaborn
